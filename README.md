# Satu Rukun

Satu Rukun merupakan website layanan publik dengan skala rukun warga

## Fitur Utama

- **Manajemen Pengguna:** Sistem login dan hak akses berdasarkan peran.
- **Pengelolaan Data:** Fitur tambah, ubah, dan hapus data secara real-time.
- **Layanan dan Transparansi:** Memberikan layanan publik dan transparansi dana.

## Teknologi yang Digunakan

- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
